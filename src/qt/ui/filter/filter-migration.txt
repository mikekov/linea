FilterEffectsDialog -> Qt FilterEditor migration checklist
============================================================

Status convention:
  [ ] planned or in progress
  [x] implemented and verified

Rules:
  - Every row must be checked before removing the GTK FilterEffectsDialog.
  - Do not mark a row [x] until the implementation is built.
  - New migration files belong under src/qt/ui/filter/.
  - Preserve current undo labels, coalescing keys, preferences, selection semantics,
    XML behavior, and document lifecycle behavior.
